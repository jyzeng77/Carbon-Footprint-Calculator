# Carbon-Footprint-Calculator
A simple website that takes information from a user and calculates their carbon footprint.

This calculator was to be embedded inside of a website for a sustainability project for when I was part of the Believe Leadership Program. Optimizing the site to be standalone and adding the features I planned is part of my future plans for this long-shelved product :D

View it and play around on its website [here](https://carbon-footprint-calculator-hazel-eight.vercel.app/)
